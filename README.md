# BurgerCredit

**BurgerCredit** es una aplicación diseñada específicamente para *TheBurgerClub*, un negocio de comida rápida, para gestionar de forma eficiente las deudas de los clientes que compran a crédito ("fiado"). La app reemplaza el uso de cuadernos y notas manuales, permitiendo al dueño llevar un control claro y organizado de los morosos.
